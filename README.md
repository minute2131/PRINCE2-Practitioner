# PRINCE2® v7 Practitioner Exam Practice Hub

Interactive PRINCE2® Version 7 Project Management Practitioner exam preparation web app with **350 questions** across **5 full-length 70-question papers**:

- **Official Sample Paper 1 — Scenario 4: NowByou** (70 questions + verbatim rationales)
- **Official Sample Paper 2 — Scenario 4: NowByou** (70 questions + verbatim rationales)
- **Extended Practice Paper 1 — Scenario 1: Data Knowledge** (70 questions + full rationales)
- **Extended Practice Paper 2 — Scenario 2: Louistown City Council** (70 questions + full rationales)
- **Extended Practice Paper 3 — Scenario 3: Findef** (70 questions + full rationales)

## Features
- Instant tick-to-check validation (**Correct** / **Incorrect**) with full option-by-option PRINCE2® v7 manual rationales and syllabus references.
- Open-book Scenario Booklet viewer (split-screen on desktop or modal drawer on mobile).
- Offline-ready Progressive Web App (`manifest.webmanifest` + `sw.js`) for iPhone and Android Home Screen installation.
